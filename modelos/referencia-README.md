# Referência sob demanda

Esta pasta guarda o detalhe que **não** precisa estar no `CLAUDE.md` (lido em toda sessão e relido a cada turno):
armadilhas de uma tecnologia, infraestrutura e deploy, contas de teste, contratos de API, decisões antigas.

- Um arquivo por assunto, com um título que diga quando ler (ex.: "leia ao mexer em deploy").
- O `CLAUDE.md` da raiz tem um **índice** "assunto → arquivo" apontando para cá.
- Seções de funcionalidade de um app ficam em `<app>/docs/contexto/funcionalidades.md`, com um índice no
  `CLAUDE.md` do app.

Metodologia: Dieta de Contexto (`@i9up/fengshui`).
